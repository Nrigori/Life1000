# Life1000 V1 产品与开发规格

## 1. 产品定位

### 1.1 产品名称

**Life1000**

### 1.2 核心概念

Life1000 是一个仅供个人使用的「人生必做1000件事」Web 应用。

它不是：

- Todo List
- 项目管理器
- 打卡软件
- KPI 系统
- 人生日记
- 任务提醒工具

它的核心意义是：

> 记录这一生真正想做的事情，并在完成以后留下文字、照片、文档和经历。

核心设计原则：

> **帮助用户记录人生，而不是管理人生。**

因此整个软件不应包含催促、截止日期、目标完成率、同比、任务提醒等明显的任务管理元素。

------

# 2. 产品平台

## 2.1 V1

以 **PC Web** 为主要使用场景。

主要适配：

- 1366px 笔记本
- 1440px 笔记本
- 常规桌面显示器

优先保证 PC 体验。

## 2.2 后续扩展

后端保持标准 REST API。

未来可以继续接入：

- 手机 Web
- Android / iOS
- 桌面程序
- 个人 Agent 程序

V1 不开发移动客户端。

------

# 3. 用户体系

软件仅供一个人使用。

V1：

- 有登录页面
- 单用户
- 不允许注册
- 不做用户管理
- 不做找回密码
- 不做角色权限系统

登录账号和密码不得硬编码在前端代码中。

后续部署时通过配置文件或环境变量配置。

------

# 4. 整体视觉风格

## 4.1 核心气质

整体视觉：

> **私人手账 + 摄影集 + 轻微档案感**

但保持现代 Web 操作体验。

不要：

- SaaS 管理后台风格
- 大面积纯白
- 极简 Todo 风
- 过度游戏化
- 大量胶囊按钮
- 夸张圆角
- 强烈阴影
- 花哨渐变

## 4.2 功能页面

主背景：

**暖米白色。**

建议参考：

- 页面背景：`#F3EBDD`
- 卡片纸张：`#F8F2E7`
- 主文字：`#3E342B`
- 次要文字：`#7A6A5B`
- 少量强调：暖棕 / 暗金

允许微调，不要求完全使用以上颜色。

背景增加非常轻微的纸张纹理。

纹理必须：

- 足够淡
- 长时间浏览不疲劳
- 不影响文字阅读

## 4.3 字体

功能正文：

现代无衬线字体。

以下内容可适当使用具有书籍感的衬线字体：

- LIFE / 1000
- 卡片编号
- 首页金句
- 大标题

## 4.4 卡片

整体规整。

细节可以略带手账感。

建议：

- 4～8px 小圆角
- 极轻阴影或边框
- 不使用夸张圆角
- 不做卡片乱序、旋转等真正的不规则布局

# 6. 首页

## 6.1 定位

首页不是 Dashboard。

首页是整个 Life1000 的：

> **个人封面。**

首次进入软件时应该首先给人一种「进入属于自己的空间」的感觉。

首页采用全屏设计。

默认不需要通过向下滚动访问其他功能。

功能通过顶部导航跳转。

------

## 6.2 首页内容

首页核心内容：

### LIFE / 1000

作为核心视觉标题。

### 随机金句

例如：

> “此心安处是吾乡。”

金句来自「金句收藏」。

每次进入首页时：

从允许首页展示的金句中随机选取一条。

完全随机。

不需要避免连续两次出现同一句。

### 日期

展示当天日期。

例如：

```
2026.09.06
```

### 人生千事数据

例如：

```
37 / 126
```

下面小字：

```
已完成 / 已写下
```

不展示：

```
完成率 3.7%
```

禁止使用“人生完成度”等表达。

### 年度时间

例如：

> **2026 已走过 68.2%**

可以使用一条非常细、低调的年度时间线。

它代表时间流逝，而不是任务进度。

不要显示：

- 还剩116天
- 年度任务进度
- Deadline

------

# 7. 首页背景

首页背景使用摄影照片。

支持两种模式：

## 7.1 固定模式

用户手动设置一张首页背景。

## 7.2 随机模式

每次进入首页：

从允许作为首页背景的图片中随机选择一张。

不自动轮播。

只有重新进入首页时才重新随机。

图片附件支持：

```
允许作为首页背景
```

开关。

这样可以防止：

- 文件截图
- 票据
- 聊天截图
- 不适合作为背景的图片

被随机展示。

如果当前没有可用照片，则显示默认背景。

# 9. 人生千事

这是软件最核心的页面。

------

# 10. 固定1000个位置

人生千事永久存在：

```
001 → 1000
```

每一个位置拥有固定编号。

编号一旦对应某件事情，不会因为删除其他事项改变。

例如：

```
011
012 —— 空白
013
```

删除第012件以后：

012 重新成为空白。

013 不移动。

数据库中：

不存在事项记录的编号即为空白位置。

------

# 11. 千事页面视图

支持：

### 卡片视图

默认。

### 列表视图

可切换。

页面右上：

```
卡片 | 列表
```

------

# 12. 卡片视图布局

主要设计基准：

普通笔记本一屏约显示：

> **5列 × 2行 = 10件**

参考卡片尺寸：

- 宽约 220～240px
- 高约 260～280px

图片约占：

> **卡片高度的45%左右**

图片不应占据整张卡片。

Life1000 首先是「人生1000件事」，其次才是相册。

------

# 13. 卡片内容

一张普通事项卡片只显示：

- 固定编号
- 封面图片
- 标题
- 分类
- 状态
- 快速完成按钮

不要显示：

- 预算
- 地点
- 完成条件
- 长文字
- 过程记录
- 评分

这些进入详情页查看。

------

# 14. 空白卡片

空白位置仍然显示编号。

例如：

```
037
```

中间：

```
＋
```

文字：

```
尚未写下
```

空白不代表“未完成”。

而代表：

> 未来还没有出现的第037件事。

------

# 15. 图片规则

如果事项存在手动设置的封面：

使用手动封面。

如果没有：

自动使用该事项最近上传的一张图片。

如果完全没有图片：

显示干净的无图片状态。

例如：

```
✦
尚无影像
```

禁止自动塞网络默认风景图。

------

# 16. 完成后的卡片

未完成事项：

显示：

```
旅行 · 未完成
```

或者：

```
学习 · 进行中
```

完成以后：

弱化分类信息。

优先显示：

```
2028.06.17 · ✓
```

视觉上让：

> “愿望卡片”

逐渐变成：

> “回忆卡片”。

------

# 17. 千事页面滚动

按编号：

001 → 1000

连续向下滚动。

不使用：

```
第1页 / 第2页 / 第3页
```

这种传统后台分页。

建议：

每次懒加载 / 渲染约50个位置。

视觉上仍然是一面连续的千事墙。

------

# 18. 搜索和筛选

页面顶部固定搜索区域。

包含：

- 搜索
- 分类
- 状态
- 卡片 / 列表切换

例如：

```
搜索______　分类▼　状态▼　　卡片 | 列表
```

搜索结果保持原始编号。

例如搜索“旅行”：

- 003
- 027
- 118
- 406

绝不重新编号为1、2、3、4。

------

# 19. 状态

Life1000 V1 只保留三种事项状态：

1. 未开始
2. 进行中
3. 已完成

不做：

- 暂停
- 延期
- 已取消
- 放弃
- 过期

如果未来彻底不想做：

直接删除该事项。

编号重新成为空白。

------

# 20. 新建事项

点击空白卡片：

例如第037件。

打开轻量新增弹窗。

内容：

```
第 037 件
```

字段：

### 标题

必填。

### 分类

可选。

### 为什么想做

可选。

按钮：

```
取消
写下它
```

整个创建流程必须足够轻。

核心原则：

> **录入要轻，记录要深。**

保存以后再进入详情页慢慢补充。


# 23. 为什么想做

独立内容区：

```
为什么想做
```

------

# 24. 完成条件

完全可选。

例如：

- □ 独自出发
- □ 至少旅行7天
- □ 拍一组自己满意的照片

允许：

- 新增
- 修改
- 删除
- 勾选

没有完成条件的事项可以完全不显示该区块。

------

# 25. 禁止目标时间

Life1000 中不得出现任何：

- Deadline
- 截止日期
- 目标时间
- 预计完成日期
- 计划完成年份
- 逾期
- 提醒

这是明确产品原则。

------

# 26. 我的记录

每件事项支持无限追加过程记录。

例如：

```
2027.03.12
突然又开始认真考虑这件事了。
```

附件：

- 图片
- PDF
- DOCX
- 其他文件

下一条：

```
2027.06.18
开始研究路线。
```

过程记录应该拥有自己的时间顺序。

------

# 27. 附件

事项支持上传：

- JPG
- PNG
- WEBP
- PDF
- DOCX
- XLSX
- TXT
- ZIP
- 其他常见文件

V1 文件保存在服务器 / 本机文件系统。

MySQL 只保存：

- 文件名
- 文件路径
- 类型
- 大小
- 所属事项
- 所属记录
- 上传时间

不要把图片二进制直接保存进 MySQL。

------

# 28. 附件分类

附件主要分：

### PROCESS

过程附件。

### COMPLETION

完成证明。

### GENERAL

普通事项附件。

图片同时可以设置：

- 是否事项封面
- 是否允许作为首页随机背景

# 29. 全部附件

详情页下方提供：

```
全部附件
```

统一浏览该事项所有：

- 图片
- 文档
- 文件

# 30. 快速完成

快速完成是 Life1000 的核心交互。

在人生千事卡片上：

提供一个明显但不过度抢眼的：

```
○
```

完成按钮。

详情页底部也存在：

```
○ 标记为完成
```

------

# 31. 完成弹窗

点击完成以后：

不能偷偷直接修改状态。

必须弹出完成窗口。

例如：

```
第 027 件
独自去一次西藏旅行
完成了
```

字段：

### 完成日期

必填。

默认当天。

允许修改。

### 完成感想

可选。

### 完成证明

可选上传：

- 图片
- PDF
- 文档
- 其他文件

### 体验评分

1～5星。

可选。

按钮：

```
取消
确认完成
```

------

# 32. 完成状态变化

确认完成：

事项状态：

```
→ 已完成
```

记录：

- 完成日期
- 完成感想
- 评分
- 完成证明

然后：

自动进入对应年份的时间轴。

自动进入统计数据。

------

# 33. 完成反馈

不要弹：

> 操作成功。

不要：

- 烟花
- 金币
- XP
- 等级
- 游戏奖励

使用克制的短反馈。

例如：

> 第027件，已经成为回忆。

或者：

> 第027个空白，被填上了。

短暂出现即可。

------

# 34. 撤销完成

允许撤销完成。

详情页：

```
更多 → 撤销完成
```

撤销以后：

恢复到完成之前的状态。

完成日期不再参与时间轴。

但：

**不得删除已经上传的完成证明、照片、文件。**

防止误操作导致数据丢失。

------

# 35. 已完成事项继续编辑

事项完成以后：

仍然允许：

- 修改文字
- 补充照片
- 补充文件
- 新增过程记录
- 修改完成感想
- 修改评分
- 修改封面

“已完成”只是状态。

不是锁定档案。

------

# 36. 时间轴

时间轴只服务于：

> 人生1000件事。

它不是人生日记。

不会记录：

- 换工作
- 搬家
- 毕业
- 普通生活事件

除非这些事情本身就是人生1000件之一。

------

# 37. 时间轴页面结构

页面主体使用：

> **年度卡片**

例如：

```
2028　　　　　　完成31件　⌄
2027　　　　　　完成18件　⌄
2026　　　　　　完成12件　⌃
```

点击年份：

展开 / 收起。

默认：

当前年份展开。

其他年份收起。

年份顺序：

最新年份在上。

------

# 38. 年度内部时间轴

年份内部：

按照完成日期从年初到年末。

例如：

```
01.17　　第012件 · 独自看一次日出
03.21　　第031件 · ……
05.03　　第047件 · 独自去绍兴旅行
```

每条只显示：

- 完成日期
- 固定编号
- 事项标题

不显示：

- 图片
- 分类
- 评分
- 长文字
- 完成感想

------

# 39. 时间轴跳转

事项标题整段可点击。

Hover：

- 文字变亮
- 鼠标手型
- 轻微下划线或位移动效

点击：

```
时间轴 → 对应事项详情
```

------

# 40. 空年份

展开显示：

> 这一年没有完成记录。

不添加：

- 总结
- 鼓励
- 年度报告
- 题记

# 41. 数据统计

不要柱状图。

不要折线图。

不要环形图。

# 42. 数据统计内容

- 首页展示开关
- 编辑
- 删除

------

# 44. 金句字段

每条金句只需要：

### 内容

必填。

### 来源

可选。

来源不拆作者和出处。

直接保存：

```
苏轼《定风波》
```

### 是否参与首页随机

Boolean。

默认：

true。

------

# 45. 金句首页逻辑

首页加载：

从：

```
include_home = true
```

的金句中：

随机查询一条。

完全随机。

不保存上一条。

不做防重复逻辑。

连续两次随机到同一句：

视为正常结果。

------

# 46. 金句搜索

只需要普通模糊搜索。

匹配：

- 内容
- 来源

不做：

- 分类

- 知识库

代表：

# 64. 项目最终体验

打开 Life1000：

看到的不是：

> 今天还有多少任务没完成。

而是：

> 自己喜欢的照片。

> 一句随机出现的话。

> 这一年已经走到了哪里。

> 已经写下多少想做的事情。

> 已经有多少事情真正成为了过去的经历。

进入人生千事：

看到的是001到1000的一整面人生愿望墙。

空白的位置等待未来慢慢出现。

完成一件事情以后：

它从一个愿望卡片逐渐变成一张带着照片、文字和日期的回忆卡片。

多年以后打开时间轴：

只需要看到：

> 2028年6月17日，第027件，完成。

点击以后：

当时留下的一切仍然在那里。

这就是 Life1000。
